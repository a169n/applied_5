# quakeloc Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build quakeloc (STA/LTA detection, AIC picking, Geiger location, FastAPI service) and its Docker, Jenkins and Minikube toolchain, then produce the assignment reports, so a push to `main` ends with the new version running in Minikube.

**Architecture:** Pure numerical modules (`model`, `synth`, `detect`, `pick`, `locate`, `stats`, `geo`) are composed by `pipeline`, which `calibrate`, `experiment`, `realdata` and `api` all share. A multi-stage Dockerfile produces test and runtime images. Jenkins-as-code runs on the Mac's Docker daemon and deploys to Minikube through a script that a `make` target can also run.

**Tech Stack:** Python 3.12, numpy, scipy, FastAPI, pytest, Hypothesis, ruff, ObsPy 1.5.1 (fetcher only), Docker, Jenkins 2.580.2 LTS (JCasC + Job DSL), Minikube, pandoc + LibreOffice.

**Spec:** `docs/design/quakeloc-design.md`. Executors read it as well: tasks cite its sections (§) instead of repeating them, and its numbers win over any paraphrase here.

## Decisions the spec leaves open

| Topic | Decision |
|---|---|
| Runtime paths | `quakeloc/paths.py`: `config_dir()`, `artifacts_dir()`, `snapshot_dir()` read `QUAKELOC_CONFIG`, `QUAKELOC_ARTIFACTS`, `QUAKELOC_SNAPSHOT`, defaulting to `./config`, `./artifacts`, `./data/real`. Runtime image: WORKDIR `/app`, `QUAKELOC_ARTIFACTS=/artifacts`. |
| Exceptions | `SignalError` lives in `detect.py`, `LocationError` in `locate.py`, `SnapshotError` in `realdata.py`. Each subclasses `ValueError`. |
| Input hashing in `manifest.json` | Hash only `*.py` and `*.json` under `src/` and `config/`, sorted POSIX relative paths, cwd-relative. `test` and `artifacts` stages both use WORKDIR `/app` with the same paths, so outputs are byte-identical ("tested = shipped"). `OPENBLAS_NUM_THREADS=1` is set in `deps`. |
| Artifacts for stage 6 | Stage 5 copies artifacts to the workspace. Stage 6 uses `docker create` + `docker cp artifacts/. t:/artifacts` + `docker start -a`, which respects the no-bind-mount rule. |
| Fast tests needing a detector | Session fixture `tiny_artifacts` in `tests/conftest.py` runs `calibrate` with tiny `n` into a temp dir. |
| Smoke `/version` check | `smoke.py` compares against env `GIT_SHA`. The smoke container uses the same image, so no extra argument is needed. HTTP is stdlib `urllib`; tests inject a `get` callable backed by TestClient. |
| Deploy logic | Stage 10 lives in `k8s/deploy.sh <image>`, called by both the Jenkinsfile and `make deploy`. |
| Dependency resolution | Resolve all three requirements files together with `uv pip compile --python-version 3.12` so the `data` image has the same numpy as `runtime`. |
| `/ready` self-test | Runs once per process and is cached on `app.state`. `/ready` returns 503 with the reason. Missing artifacts never stop the process from starting, so `/health` stays up. |

## Review Focus

1. `/pick` receives NaN/Infinity samples, `fs_hz ≤ 0`, or a very short trace: expect 422, never 500 (Task 10).
2. `/locate` receives a duplicate or unknown station, `sigma_s ≤ 0`, or non-finite times: expect 422 naming the problem (Task 10).
3. A real station is flat-lined, contains NaN or a gap, or has a different sampling rate (HHZ 100 Hz vs BHZ 40 Hz): that station is skipped with a recorded reason, the rest of the event still locates, and the filter uses that station's own `fs` (Task 9).
4. A snapshot file is tampered with while the service runs: `/events/{id}/locate` returns 503 with a clear message, while `/ready` stays independent of the snapshot (Task 10).
5. A real event ends with fewer than 4 usable picks: reported as "not located" in `relocation.csv` and as 422 from the API, without aborting the batch (Task 9, Task 10).
